# Эмулятор оболочки ОС (Вариант №6)

Учебная практическая работа по дисциплине
**«Конфигурационное управление»**.

- **Вариант:** №6
- **Язык реализации:** Python 3.10+
- **Тип интерфейса:** CLI
- **Текущий этап:** Этап 1 — REPL

## 1. Общее описание

Эмулятор командной строки UNIX-подобной ОС.
На этапе 1 реализован REPL-цикл с командами-заглушками
`ls`, `cd` и командой выхода `exit`.

**Особенность варианта №6:** приглашение формируется на основе
**реальных данных ОС** — имени пользователя и хоста.

## 2. Функции и настройки

### Команды

| Команда | Описание |
|---|---|
| `ls` | Заглушка. Выводит имя и аргументы. |
| `cd` | Заглушка. Выводит имя и аргументы. |
| `exit` | Завершить работу. |

### Приглашение

Формат: `username@hostname:cwd$`

Пример: `ivan@my-laptop:~$`
